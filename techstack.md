# Tech Stack

Stack inventory for `rosak_backend`. Source of truth for versions: `pyproject.toml`
(ranges) and `requirements.lock` / `requirements-dev.lock` (pins, generated by
`rye lock`). Versions below were checked on 2026-10-21. Commands: [AGENTS.md](AGENTS.md);
architecture: [docs/APPS.md](docs/APPS.md).

| Layer           | Choice                                                                                                                  |
| --------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Language        | Python 3.13 (`python:3.13-slim-bookworm`, `.python-version`)                                                            |
| Framework       | Django 5.2 (`django==5.2.*`, locked 5.2.17) with GeoDjango; Django REST Framework for `/upload/` and chart feeds       |
| GraphQL         | Strawberry GraphQL 0.323.2 + strawberry-graphql-django 0.82.1 (`<0.83`); single async endpoint `POST /graphql/`         |
| App server      | Granian 2.8.3 (ASGI, uvloop) on `:8001` behind nginx (`:8000`)                                                          |
| Primary DB      | PostGIS 17-3.5 (`postgis/postgis:17-3.5-alpine`); psycopg2-binary                                                       |
| Telemetry DB    | TimescaleDB (pg16) for `jejak`; optional, enabled only when the `TIMESCALE_*` env vars are set (`JEJAK_ENABLED`)         |
| Cache + broker  | Valkey 9 (`valkey/valkey:9-alpine`) via the `redis` client 5.2.1 (`redis://` URL); `DummyCache` when `DEBUG=True`; django-cachalot for ORM caching |
| Async jobs      | Celery 5.6.3, django-celery-beat, django-celery-results (beat schedule lives in `rosak/celery.py`)                      |
| Auth            | Firebase bearer token, verified with firebase-admin                                                                     |
| Media           | Pillow + pillow-heif, Discord CDN (webhook), Imgur (`imgurpython` fork), S3-compatible storage via boto3 / django-storages |
| Integrations    | python-telegram-bot, X API (official-post ingestion), reCAPTCHA v3, Firebase Functions callable (`extractIncidentData`) |
| Observability   | sentry-sdk (non-DEBUG only), django-health-check, django-debug-toolbar (DEBUG only)                                     |
| Data utilities  | polars, pendulum                                                                                                        |
| Model helpers   | django-safedelete, django-simple-history, django-ordered-model, django-tree-queries, django-choices-field, django-model-utils, django-cleanup |

## Tooling and CI

- **Dependencies:** `rye` manages `pyproject.toml` and the lockfiles; the `Dockerfile`
  installs them with `uv` (`ENVIRONMENT=dev` uses `requirements-dev.lock`).
- **Lint / format:** ruff (`.ruff.toml`; 0.16.4 in the dev image) via `pre-commit`.
- **Types:** mypy 2.4.0 with the Strawberry plugin (`mypi.ini`).
- **Tests:** Django test runner; `tests/` is pytest-style (pytest, pytest-asyncio and
  pytest-django are present in the app container but not pinned in the lockfiles).
- **CI:** GitHub Actions in `.github/workflows/` (`test.yml`, `push-image-ghcr.yml`,
  `cleanup-image.yml`); Dependabot. A Helm chart is in `.k8s/charts/`.
