# 2026-09-15

## [2026-09-15] common: OCI Object Storage rejects Telegram image uploads (aws-chunked)

- `TemporaryMedia` uploads via `POST /upload/` (and any S3 put) failed with
  `botocore.exceptions.ClientError: NotImplemented: AWS chunked encoding not supported`.
- Root cause: botocore >= 1.35 defaults `request_checksum_calculation` to
  `when_supported`, adding a CRC32 trailer checksum to streaming `PutObject`
  (`Transfer-Encoding: chunked` + `Content-Encoding: aws-chunked`). OCI Object
  Storage's S3-compat endpoint rejects aws-chunked with 501.
- Fix (`rosak/settings.py`): `os.environ.setdefault("AWS_REQUEST_CHECKSUM_CALCULATION", "when_required")`
  disables the default checksum. Verified: storage client config reports
  `when_required`; `signature_version`/`addressing_style` unchanged; `manage.py check` clean.
