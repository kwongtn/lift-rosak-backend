# 2026-09-30

## Incident: `publicSocialMediaLinks` — `lastWeekOnly` + `alignPageToDay`

- **What**: two optional arguments on the root `publicSocialMediaLinks` query,
  inferred from the resolver signature (no `schema.py` edit), for the frontend's
  collapsed "Last Week" section.
  - `incident/schema/resolvers.py`: new module-level pure helper
    `last_week_start(now)` = local midnight six days before `now`
    (`datetime.combine((now - timedelta(days=6)).date(), time.min)`; naive-local
    like `service_day_start`). `get_public_social_media_links` gains
    `last_week_only: bool = False` — filters `created >= last_week_start(now)`
    alongside `current_service_day_only`, before `total_count` — and
    `align_page_to_day: bool = False`.
  - `align_page_to_day` (complete-day pages, **no cap**): after the existing
    `first + 1` lookahead fetch, if the lookahead shares the page's last local
    calendar day, the lookahead plus every remaining row of that day is appended
    via `queryset.filter(created__date=<day>, keyset-after(lookahead))`, so the
    page may exceed `first` (a whole day lands together). `endCursor` = the new
    last row; `hasNextPage` = an `.aexists()` keyset probe after it. A lookahead
    on a different day (or none) leaves the page byte-identical to before.
    `total_count` stays the full filtered-set size, cursor- and
    alignment-independent. Docstring documents both flags; the connection type
    shape (`SocialMediaLinkConnection`/edge/pageInfo) is untouched.
  - `rosak/tests/snapshots/schema.graphql`: one line regenerated (the two new
    args) so the schema snapshot gate stays green.
  - Tests (`incident/tests.py`): new `PublicFeedLastWeekAndDayAlignTests`
    (8 tests) — the exact 00:00 six-days-ago boundary is included while 23:59
    seven days ago and much older rows are not; `alignPageToDay=false` still
    returns exactly `first`; alignment completes a 3-row day at `first=2`
    (page exceeds `first`, `hasNextPage=true`, `endCursor` = last day-A row) and
    the follow-up `after=endCursor` returns the older day; a 5-row final day
    returns whole with `hasNextPage=false`; a page already ending on a day
    boundary is untouched; a final page smaller than `first` is returned whole;
    `lastWeekOnly` + `alignPageToDay` combine; `totalCount` respects the window
    and ignores alignment. Rows are stamped with `.update(created=…)` after
    create (the `auto_now_add` trap, catalogued in `MISTAKES.md`).
  - Docs: the resolver-arguments paragraph in `docs/components/incident.md`
    documents both flags and their semantics.
