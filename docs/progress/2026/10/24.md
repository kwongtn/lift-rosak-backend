## [2026-10-24] spotting: report_spotting_today at 03:01 for the 27-hour service day

- `report_spotting_today` fires at 03:01 local, not 00:00 (`rosak/celery.py`, `crontab(hour="3", minute="1")`). Each run digests the submissions in `[D 03:01, D+1 03:01)`, selected by `Event.created`, and is headed with D. A run on Tuesday 03:01 covers `[Mon 03:01:00, Tue 03:01:00)` and is headed Monday. Submission time was chosen over the user-entered `spotting_date`. (`f03d8d8`)
- D is `effective_spotting_date(now)` minus one day, with the default 03:00 cutoff rather than 03:01, so a worker clock up to 60 s behind beat's still reports the window that just closed. A run from 03:00:00 to 03:00:59 reports the window that closes at 03:01, which is still open for up to 60 s. A run before 03:00 reports the last fully closed window. A late pickup reports the same window as an on-time run. (`f03d8d8`)
- `telegram_provider.utils.get_daily_updates` takes a keyword-only `created_between`. With a window, it selects spotted vehicles by `Event.created` in `[start, end)`. Without one, the `spotting_date` path is unchanged, so `/spotting_today` keeps its `spotting_date` and 03:00 cutoff. (`f03d8d8`)
- Tests: `ReportSpottingTodayTaskTests` (`spotting/tests.py`) replaces the old 00:00 test. The new checks cover the 03:01 beat and its timezone, the window edges, submission time over `spotting_date`, on-time and late runs, runs before 03:01, and a window with no submissions. `GetDailyUpdatesTests.test_without_a_window_events_are_picked_by_spotting_date` (`telegram_provider/tests.py`) pins the `spotting_date` path. Against the parent commit, the beat, window-edge, submission-time and on-time/late tests fail.

- Deploy: the Celery containers do not autoreload, so restart `celeryworker` and `celerybeat` together, or neither. A beat-only restart runs the old task at 03:01 and posts today's near-empty digest under today's date. Where beat's schedule file persists (the dev stack), a restart after the 03:01 slot fires one catch-up digest, because the stored last run is older than that slot.
